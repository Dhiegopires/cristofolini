SaaS Dashboard

Analytics dashboard concept with a companion landing page

UI/UX Design · 2024 · Concept project

Overview

This concept pairs a SaaS analytics dashboard with a companion landing page. The goal is to show how a product system can stay coherent across daily-use screens and the marketing surface that introduces it.

Unified UI/UX concept

The dashboard and landing page share typography, spacing, and card logic so the product feels like one system. Strong hierarchy keeps data readable while the page still supports evaluation and sign-up.
