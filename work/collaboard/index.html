Collabboard

B2B CRM workspace concept for product teams

UI/UX Design · 2024 · Concept project

Overview

Collabboard is a conceptual B2B CRM workspace built around daily decision-making. The interface explores how a sales team can move from pipeline review to account context without switching tools or losing clarity.

The home view acts as a quick status snapshot: high-level KPIs, current priorities, and recent activity sit together in one place. The goal is to give managers and reps the same picture of what needs attention now.

Pipeline board: stage based work view

The pipeline board organizes opportunities into clear columns for each stage, from New to Negotiation. Each card surfaces the essentials at a glance so the board feels like a live workspace instead of a spreadsheet.

Deals table & deal details

For reviews and forecasting, leaders need a view that can be sorted and scanned line by line. The Deals screen complements the board with a table that keeps the same language and structure.

The Deal details view brings context into a single layout: a concise header above an activity timeline so anyone can read the state of a deal without a separate briefing.
